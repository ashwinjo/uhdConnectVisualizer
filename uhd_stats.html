How to Use

      

      

        
1. Enter the UHD device IP in the left panel. If prompted about a certificate, visit the URL in a new tab and accept it, then return here.

        
2. Click Configure Ports to select which ports to monitor. Port list is fetched live from the device.

        
3. Click Start Polling to begin auto-refreshing metrics every 3 seconds. The button turns green while active.

        
4. Click Clear Metrics to reset counters on the selected ports only. Confirm when prompted.

        
5. Use Get Configuration in the left panel to inspect the current device config, or Set Configuration to push a JSON config to the device.
